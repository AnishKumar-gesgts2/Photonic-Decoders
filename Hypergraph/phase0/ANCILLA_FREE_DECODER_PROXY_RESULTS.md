# Ancilla-free joint-MAP Phase 0 proxy — 2026-09-26

The reproducible output is [results.json](../outputs/phase0_ancilla_free_decoder_proxy/results.json). Run `PYTHONPATH=phase0 python phase0/run_ancilla_free_decoder_proxy.py` from `Hypergraph`. The study uses 12,000 training shots, 1,500 independent selector-tuning shots, and 5,000 held-out shots **per setting**. A separately trained zero-joint channel is used for its negative control. Test shots and seeds are identical across decoders within each setting.

This is an ancilla-free **encoded periodic-sector proxy**. Each encoded fusion uses four two-photon BSMs, ideal 50% *average* complete Bell discrimination, and the existing $(2,2)$-Shor parity reconstruction. Full versus partial records follow the ideal Bell branch after the fault: A/C partial outcomes retain $X$, while B/D partial outcomes retain $Z$. The noise model assumes 0.2% independent physical parity flips and, in the nominal setting, a 0.5% joint A-fusion $XX/ZZ$ flip. A [later local optical gate](IMPROVED_IDEA_GO_NO_GO.md) identifies a specified input Pauli $Y$ as one mechanism that can make this physical-A bit flip, but its source incidence remains an assumption, and encoding makes its joint action outcome-dependent. The 3×3×3 Stim six-ring bulk provides local detectors and three nonlocal diagnostic sectors. It has no finite boundaries or declared memory logical. An undeformable sector is counted as a failure for every decoder.

All decoders receive the same measured parity values, known/erased mask, and record-conditioned calibration. The *core* record also includes the four physical full/partial/lost classes. The *detailed* record adds only disagreement flags from measured redundant physical parities. Equally informed MWPM uses erasure-contracted checks and conditional graph marginals. The correlation-aware matching control uses four-state belief propagation followed by that matching step. The joint hypergraph arm solves a global four-state configuration-MAP integer program; one joint $XX/ZZ$ event remains one categorical fault and must satisfy every observed check. It is configuration MAP rather than marginal logical-class MAP. No decoder sees the latent joint-fault labels on test shots.

At the nominal setting, 73.82% of shots have an undeformable sector. Among the 1,309 measurable shots, MWPM fails on 321 and joint MAP on 262, a 4.51-point conditional difference. The overall failure rates are 80.24% and 79.06%, respectively. Joint MAP also beats the equally informed belief-matching control by 0.54 points overall (95% paired interval 0.06 to 1.02 points). The result is a valid **model-conditional proxy gain**, not a native logical error-rate result.

The core-to-detailed record improvement is 3.44 points for MWPM and 3.84 points for joint MAP. The *extra* metadata benefit for MAP is 0.40 points (95% paired interval −0.22 to 0.98). **There is no resolved evidence that the disagreement metadata helps MAP more than MWPM.** This experiment does not include a derived raw-PNR likelihood or source herald, so it cannot answer whether those richer records would change the interaction.

The selector threshold was chosen on the separate tuning split by maximizing failure reduction minus a fixed 0.0005 penalty per activated shot and was copied unchanged to held-out settings. On nominal held-out data it activates on 17.76% of *all* shots, or about 67.8% of measurable shots. Its 1.10-point gain retains most of global MAP's 1.18 points, but activation is dense among decodable shots. MAP averaged 6.41 ms per measurable shot versus 0.23 ms for MWPM in this run. **No-go for a sparse selective-compute claim at this threshold and cost objective.**

**Phase 0 decision:** Go for the narrow statement that global joint-fault decoding beats equally informed MWPM in this predeclared, assumed ancilla-free proxy channel at the nominal and shifted settings. No-go for claiming a physical ancilla-free hypergraph advantage, a larger metadata benefit than MWPM, a sparse selector, or a bounded six-ring logical win. The physical claim still requires an optical or measured $P(R,A\mid\theta)$ for the ancilla-free encoded fusion, a native bounded encoded six-ring memory, and the plan's full frozen physical grid. A joint fault at a convenient rate cannot stand in for those gates.
