# Improved ancilla-free idea: Phase 0 go/no-go audit — 2026-09-26

The improved idea is to beat equally informed calibrated MWPM on **logical failure** by preserving common-cause errors between the $XX$ and $ZZ$ outcomes of ancilla-free encoded fusions. The [FBQC paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC9938229/) provides the six-ring resource/check framework and explicitly treats the two Bell outcomes as separate syndrome-graph edges. This audit tests a **specified** fault, Pauli $Y$ on one incoming data photon before an ideal two-photon dual-rail Bell analyzer. It does not assume that such faults occur at a particular rate in a real source.

Run `PYTHONPATH=phase0 python phase0/run_ancilla_free_pauli_gate.py` from `Hypergraph`. Its machine-readable [result](../outputs/phase0_ancilla_free_pauli_y_gate/results.json) and regression tests cover optical normalization, the $Y$ transformation, ideal encoded reconstruction, and Stim periodic support. The previous [ancilla-free decoder proxy](ANCILLA_FREE_DECODER_PROXY_RESULTS.md) uses the same ideal branch-dependent BSM class rule and a joint A-fusion bit flip, now identified as the action of this specified input $Y$ fault. Its $0.5\%$ physical-A incidence remains an assumption.

| Required gate | Test and observation | Decision |
|---|---|---|
| Local optical action | Exact four-mode Fock model: a pre-BSM $Y$ maps conclusive `psi_plus` to original `phi_minus` and `psi_minus` to `phi_plus`, flipping both parity bits. Full-record probability is 50% at ideal detection. Partial records flip the known parity while the other remains unavailable. Cutoffs 4 and 5 agree. | **Pass for this specified Pauli fault.** |
| Observable herald | Under a uniformly mixed Bell input, the raw PNR distribution is identical with and without $Y$ at efficiencies 100%, 99.5%, and 95% (total-variation distance zero). | **No raw-click herald for this fault.** Syndrome and encoded redundancy may still carry information. |
| Encoded action | Exact enumeration of 32 equally weighted ideal encoded input assignments after $Y$ on physical fusion A: 16 joint encoded $XX/ZZ$ flips, 8 $XX$-only flips, 8 cases with $ZZ$ unavailable. The shot generator reproduces these fractions. | **Pass, conditional:** an input $Y$ is not a joint encoded hyperedge on every outcome. |
| Code support | The existing Stim periodic six-ring bulk gives a four-check signature for a simultaneous fusion-outcome flip. Applying this support to an encoded fusion in a finite memory is still unverified. | **Pass only on periodic bulk.** |
| Decoder accuracy | With an assumed $0.5\%$ A-fusion fault rate, the periodic-sector proxy gives 80.24% failure for equally informed MWPM and 79.06% for global joint MAP on 5,000 held-out shots. Separately, a declared fusion-to-$Y$ adapter in a bounded rotated-$d=3$ memory gives 319 versus 67 logical failures on 20,000 shots at an assumed 3% joint rate. | **Pass for the stated models; neither run is a native encoded six-ring logical test.** |
| Source incidence and complete action channel | No characterized probability for this physical source $Y$, no source-herald model, and no complete record-conditioned operation through the encoded resource under loss, distinguishability, or preparation faults. | **Not passed.** |
| Native bounded encoded six-ring memory | Current code has a periodic six-ring bulk and a separate rotated surface-code logical proxy. It lacks the paper's boundary substitutions, finite encoded six-ring logical observable, and an injected-fault agreement test there. | **Not passed.** |

**Decision: GO for the local mechanism and accuracy-first effective-channel research; NO-GO for claiming a physically grounded ancilla-free FBQC logical advantage over MWPM now.** This is a claim gate, not evidence that hypergraph decoding cannot help. The common-cause fault is optically representable, but its rate is uncalibrated and the native bounded logical comparison is absent. The 3% effective-memory result must not be substituted for the 0.5% physical-A proxy or a measured device rate.

The subsequent [full optical-action audit](PHYSICAL_CHANNEL_AUDIT.md) also found that the earlier extra-plus-photon branch projection discarded Bell coherence in every accepted record. Its projected joint-$Y$ weight is withdrawn as a physical rate; it cannot fill the missing incidence/channel gate.

**Exact resume criterion:** specify and validate a source process with a measured or independently justified $Y$ incidence and uncertainty; derive the full $P(R,A\mid\theta)$ for its loss and partial-outcome classes; implement the paper-consistent finite encoded six-ring boundaries and logical membrane; verify each admitted injected fault against Stim; then freeze the physical grid and run identical-shot global MAP, calibrated MWPM, and belief matching. Report unsupported action mass and every grid cell. Only a resolved held-out logical advantage at that gate warrants a physical **go** decision. Runtime and a selective threshold follow accuracy.
